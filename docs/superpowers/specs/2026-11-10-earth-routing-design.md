# TaxiDriver Earth: маршруты А → Б и от машины

Дата: 2026-11-10. Статус: проект для проверки и согласования. Программный код ещё не изменён.

## Цель и подтверждённый объём

Пользователь выбрал для первой тестовой Earth-сборки одновременно:

1. произвольные точки А и Б, выбираемые через комбобоксы с поиском мест;
2. текущую позицию машины как начало и выбранную точку Б как конец;
3. маршруты любой протяжённости, которую поддерживает маршрутизатор и связная дорожная сеть, включая путь через материк;
4. использование сетевых возможностей BeamNG.Earth, без собственной копии мировой дорожной сети;
5. отдельную ветку от TaxiDriver 5.0.0, тестирование до объединения.

Ветка `codex/earth-integration` создана от `v5.0.0`, commit `604dc54cb15380e3db7e05dcc00f6b19bcd3c076`. Основной стек TaxiDriver остаётся Vue 3 + GE Lua. Пользователь не поручал автоматически переносить автомобиль, менять графические настройки Earth или возобновлять живые проверки AI Driver.

## Проверенные исходные контракты

Исследована Earth 1.9.1-beta, commit `e1c72abf66a42f6e877c3e1de8839352360913fc`. Ключевые Lua-файлы совпадают с клиентским модом из приложенного Host ZIP после нормализации перевода строк. Подробности и источники: `EARTH_RESEARCH.md`.

- Публичный API Earth 1.1 предоставляет состояние, позицию, GPS-цель от текущей позиции и события.
- Поиск и произвольный расчёт пути пока находятся во внутренних интерфейсах.
- Обычный запрос маршрута также заменяет общий коридор предзагрузки и запрашивает высоты. Он не годится для независимого предпросмотра.
- Расчёт пути использует OSRM через приложение Earth; Earth сокращает конечную линию до 6000 точек.
- Загрузка мира вокруг игрока и получение линии дальнего маршрута — разные операции.
- Имеющийся ZIP предназначен для BeamMP-хостинга. Он не содержит полноценное приложение Earth, необходимое игроку.

## Подходы и выбранное направление

| Подход | Что даёт | Компромисс |
| --- | --- | --- |
| Только Б через текущий публичный GPS API | Минимальная интеграция | Не выполняет выбранный пользователем объём первой сборки. |
| А → Б через обычный внутренний `requestRoute` | Произвольные координаты без нового сообщения | Вмешивается в активную предзагрузку, получает высоты; не подходит для независимого предпросмотра. |
| Независимый маршрутный запрос в API Earth | Оба режима, сеть и маршрутизатор остаются у Earth | Нужна согласованная тестовая сборка приложения и клиентского мода Earth. |

Пользователь выбрал оба режима; для них предлагается третий подход. Расширение Earth должно быть небольшим, аддитивным и отдельно поставляемым для теста. Это техническое предложение автора документа, а не уже одобренное пользователем изменение стороннего приложения.

## Поведение интерфейса

- На стартовом экране появляется кнопка «Earth-маршрут», когда обнаружен API Earth. Она открывает отдельную панель в текущем стиле TaxiDriver, без общего редизайна.
- Режим начала: «Моя машина» или «Выбрать А». В первом режиме поле А отображает текущую позицию; во втором доступен комбобокс.
- Поле Б всегда является комбобоксом. Поля содержат текстовый поиск и список до 8 мест с названием, регионом/страной и координатами. Это список результатов запроса, а не каталог всех городов мира.
- Поиск отправляется по Enter/кнопке; перемещение по результатам стрелками, Enter для выбора, Escape для закрытия. Один ввод букв не вызывает сетевой запрос. Незавершённый текст не считается выбранной точкой.
- После изменения А, Б или режима предыдущий результат помечается устаревшим и не может быть запущен.
- «Построить» запрашивает независимый предпросмотр. Состояния: готов к запросу, ожидает, готовый маршрут, нет автомобильного пути, сервис не ответил, Earth отключён, несовместимая версия API.
- Результат: подписи А и Б, полная длина, расчётное время. Первый этап не требует собственной мировой карты; обзорную линию можно добавить позже без изменения контракта.
- «Навигация к Б» запускает GPS Earth от фактической позиции автомобиля. Для произвольного А → Б рядом явно написано, что это предпросмотр выбранного пути, а навигация к Б начнётся от машины. Предпросмотр не выдаётся за маршрут, который автомобиль уже начал проходить.
- Никаких автоматических телепортаций. Если машина далеко от А, пользователь может отдельно назначить А как GPS-цель, доехать и после этого назначить Б. Переход не происходит без действия пользователя.
- Форма не запускает платный заказ, не выдаёт награду и не меняет условия текущей поездки. Дальние пассажирские/грузовые заказы требуют следующей отдельной задачи по переносу экономики на географические цели.
- Активную пассажирскую/грузовую навигацию нельзя заменить из формы незаметно: предпросмотр остаётся доступен, кнопка запуска GPS в этом состоянии отключена с объяснением. Это предотвращает конфликт двух владельцев стрелок.

Это предложенные детали UX. Подтверждённые требования пользователя — два режима, комбобоксы и длинные маршруты; остальные решения подлежат согласованию с этим документом.

## Граница TaxiDriver ↔ Earth

Новый модуль TaxiDriver `earthAdapter.lua` — единственное место обращения к Earth. Он проверяет API major и наличие возможностей; не читает `core._state()` и не подменяет `net.send`, GPS или функции Earth.

Публичные состояния: `absent`, `unsupported`, `disconnected`, `outsideWorld`, `loading`, `ready`. Earth должен быть подключён и мир открыт; для начала навигации дополнительно требуется готовность окружения и автомобиль. Предпросмотр двух выбранных точек может работать во время локальной подгрузки мира, если приложение уже подключено.

Предлагаемое аддитивное расширение Earth API — minor 1.2 с возможностями `placeSearch` и `routePreview`. Это локальный проект контракта, не утверждение о существовании API 1.2 у автора Earth.

### Асинхронный контракт

- `searchPlaces(query, options)` → непрозрачный билет либо `nil, reason`.
- `previewRoute(from, to, options)` → билет либо `nil, reason`; `from/to` содержат WGS84 `lat/lon`.
- `takeRequest(ticket)` → `nil` пока ждёт, либо конечный результат; результат потребляется однократно.
- `cancelRequest(ticket)` помечает запрос отменённым и освобождает локальный результат. Поздний ответ отбрасывается; отмена не обещает прервать уже исполняющийся HTTP-запрос к внешнему сервису.
- Билет включает поколение соединения. После переподключения старые билеты и результаты не принимаются.
- Сервер объявляет поддержку в hello. Наличие новой Lua-функции без соответствующей возможности сервера не считается поддержкой.

Для новых сообщений используются отдельные имена и отдельная таблица результатов, а не общие числовые ID поиска/маршрута существующей карты. Это исключает перехват результата GPS или поиска Earth.

### Результаты

Поиск: `{status, results=[{name, detail, lat, lon}], error?, attribution}`. Приложение использует существующий `geocode.search(..., full=True)` и существующие сетевые лимиты. Текущий поиск Earth смешивает OSM-сервисы и Wikipedia/Wikidata; в интерфейсе указана фактическая атрибуция Earth. Не обещать происхождение исключительно OSM.

Маршрут: `{status, from, to, distanceM, durationS, points?, error?, attribution}`. В первом UI достаточно метаданных; полная геометрия не пересылается в регулярных HUD-патчах. `NoRoute` отличается от отключения и тайм-аута. Ошибка не подменяется расстоянием по прямой.

Координаты проверяются на конечность и диапазон. Строка поиска ограничена 200 символами, результат — 8 местами. Детали схемы сообщений и названия констант оставлены исполнителю, семантика этого контракта обязательна.

## Расширение приложения Earth

- Отдельный обработчик предпросмотра вызывает существующий `routing.plan` и сетевой fetcher Earth в рабочем потоке.
- Он не вызывает `Connection.route`, `_route_elevation`, `route_download`, не меняет `route_points`, `route_dl_version`, активную GPS-цель и данные предзагрузки.
- Один активный предпросмотр и один ожидающий запрос на клиентское соединение; устаревшая ожидающая заявка заменяется новой. Никакой неограниченной очереди в executor.
- Поиск также идёт через существующий `geocode.search` и fetcher. Ограничения общие с интерфейсом Earth, отдельного обращения TaxiDriver в интернет нет.
- Начальный HTTP-запрос и его разбор остаются у Earth. Верхняя граница 6000 точек относится к итоговой геометрии, не к сырому HTTP-ответу. Для production нужно отдельно проверить максимальный ответ и пиковую память на длинном пути; не обещать постоянный расход по одному этому лимиту.
- Валидация новых возможностей и раздельных ответов добавляется в протокольные проверки Earth.
- Предлагаемый тестовый патч к точному upstream-коммиту хранится в TaxiDriver `integrations/beamng-earth/` с инструкцией применения и тестами. Исходная исследовательская копия остаётся в игнорируемом `dist/research`.
- Для воспроизводимости фиксируются версии клиента/приложения и хеш патча. Для первой проверки допустим запуск приложения Earth из исходников; автоматическую установку и замену пользовательской Earth-сборки выполнить только после подготовки работающего тестового комплекта.
- Тестовый комплект и архив TaxiDriver хранятся отдельно от стабильных выходных файлов. Две сборки TaxiDriver с одинаковыми Lua/UI-путями одновременно не подключаются. Порядок переключения и возврата описывается в инструкции; подготовка патча не означает автоматическую замену установленного приложения Earth.
- Публичный PR автору Earth и сообщения ему не отправляются без отдельного поручения пользователя. После принятия контракта upstream зависимость от тестового патча можно убрать.

## Географическое состояние и жизненный цикл

- Выбранные места сохраняются как WGS84, а не XYZ или ID локальных дорожных узлов.
- Для режима «Моя машина» координаты старта снимаются при нажатии «Построить», а не фиксируются навсегда при открытии формы. Этот старт сохраняется с результатом, чтобы было понятно, откуда рассчитан предпросмотр.
- При старте GPS Earth сам рассчитывает путь от актуальной позиции; предпросмотр не переносится в AI как цепочка всех дорожных узлов.
- Сохраняются режим и выбранные именованные А/Б, история до 12 мест. Билеты, ошибки, активный статус запроса и линия маршрута между сессиями не сохраняются.
- Кэш поиска: до 32 ключей × 8 мест с TTL 10 минут, включает строку и географическое смещение поиска. Данные обычных профилей и кэшей 5.0.0 не мигрируют ради этой формы.
- Земной планировщик не вызывает обычный `routePlanner` для удалённой цели. Он не добавляет Earth-маршруты в существующий XYZ-кэш карты.
- Закрытие формы отменяет её поиски и предпросмотры; запущенная пользователем навигация принадлежит Earth и продолжает работу. Выгрузка TaxiDriver не очищает произвольный GPS Earth.
- Переподключение очищает билеты, флаги ожидания и кэш ответа текущей операции. Выбранные точки сохраняются. Старый результат остаётся только как явно неактуальный предпросмотр, без разрешения запуска по старому билету.
- На обычных уровнях Earth-функциональность не создаёт опросов и не меняет диспетчер/карту/профили.

## Производительность

Проектные бюджеты, которые нужно проверить измерением:

- ни одной синхронной сетевой операции в GE Lua или Vue;
- максимум один активный предпросмотр от TaxiDriver; повторное нажатие не создаёт очередь;
- явный поиск, без запросов на каждую букву и без периодического получения списка городов;
- метаданные состояния не чаще 5 Гц, только когда нужен Earth-экран; ожидание ответа обрабатывается с той же частотой;
- карта дальнего маршрута не пересобирается каждый кадр и не хранит мировой граф;
- возможный обзор: до 512 точек в Vue, обновляется только при смене результата;
- ограниченный кэш и история, удаление устаревших билетов и поздних ответов;
- не включать `Fast`, полную предзагрузку или дополнительные потоки Earth из TaxiDriver.

Сама генерация окружения Earth может загружать CPU/RAM независимо от такси. Измерения разделяют время и память TaxiDriver, Earth, а также исходный и тёплый кэш. Длина маршрута не гарантирует его доступность у внешнего сервиса.

## Проверка и критерии готовности

1. Lua-контракт адаптера: Earth отсутствует/старый/новый; новый клиент со старым сервером; неверные координаты; отмена; переподключение; поздние ответы; ограниченность очереди/кэша.
2. Earth-server: предпросмотр действительно вызывает существующий маршрутизатор, но не меняет GPS/предзагрузку и не запрашивает высоты. Ошибка/тайм-аут не портит активный маршрут.
3. Vue: оба режима, клавиатура комбобоксов, одинаковые названия, Unicode, редактирование выбранной строки, повторные нажатия, закрытие во время ожидания, восстановление после новой сессии.
4. Реальные запросы через приложение Earth: короткий маршрут, другой город, путь на несколько тысяч км, недоступная автомобильная связь. Делать ограниченное число осмысленных запросов, повторные проверки — на сохранённых ответах.
5. Проверить 100 циклов формы/ответов: подписки и таймеры возвращаются к исходному уровню, кэш достигает предела и больше не растёт. Не объявлять выигрыш FPS без измерения.
6. Проверить при активной GPS-навигации Earth: независимые А → Б не заменяют её и не сбрасывают коридор предзагрузки. Это главный критерий расширения API.
7. Смена якоря Earth не меняет выбранные географические А/Б. Первая версия не заявляет совместимость дальних оплачиваемых заказов или AI Driver только по результату теста планировщика.
8. Исходные 45 UI-тестов и Lua-регрессии TaxiDriver проходят. Новый тестовый архив явно отличается от стабильной 5.0.0 и сопровождается инструкцией возврата.
9. Выполненные локальные тесты, реальный совместный запуск и непроверенные сценарии перечисляются раздельно. До проверки merge и стабильный релиз не выполняются.

## Решения исполнителя и открытый вопрос

Предложены исполнителем: отдельная панель без редизайна, явный поиск, лимиты кэша, схема асинхронных билетов, аддитивный API 1.2 и тестовый патч Earth. Они не приписываются пользователю.

Для начала реализации требуется согласовать именно использование тестового расширения приложения Earth: стандартная Earth 1.9.1-beta не предоставляет независимый публичный предпросмотр А → Б. Поддержка обоих режимов выбрана пользователем, но изменение стороннего приложения и описанная семантика навигации ещё не подтверждены.

Независимая проверка проекта выполнена 2026-11-10: других существенных пробелов для составления плана не обнаружено; вопрос зависимости от изменённого приложения и клиентского мода оставлен пользователю.
